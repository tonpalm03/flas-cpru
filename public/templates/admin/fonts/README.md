# ฟอนต์เอกสารธุรการ

THSarabunPSK-Regular.ttf และ THSarabunPSK-Bold.ttf มาจาก https://github.com/SarabunConsortium/TH-Sarabun-PSK พร้อม LICENSE ที่เก็บใน THSarabunPSK-LICENSE.txt ไม่แก้ไขไฟล์ฟอนต์ ใช้ใน preview บันทึกข้อความและฝัง regular font ใน Word เพื่อคงระยะตัวอักษรบนเครื่องที่ไม่ได้ติดตั้งฟอนต์

ต้นฉบับ PDF ใช้ TH Sarabun IT๙ และ TH SarabunPSK ระบบใช้ PSK พร้อมแปลงตัวเลขหัวเอกสารเป็นเลขไทย ไม่ฝังฟอนต์แบบ subset ที่สกัดจาก PDF เพราะใช้กับข้อความใหม่ได้ไม่ครบ
