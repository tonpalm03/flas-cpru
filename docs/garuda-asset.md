# ตราครุฑในหน้าตัวอย่างเอกสาร

อัปเดต 4 ตุลาคม 2569

- `public/garuda.png` คัดลอกโดยตรงจาก `word/media/image1.png` ในเอกสาร `โครงการคณะ-20260928T151834Z-1-001/โครงการคณะ/3-หนังสือภายใน ,ภายนอก ต่างๆ/001.1 ตย.หนังสือเชิญวิทยากร ภายใน.docx`
- ภาพต้นฉบับเป็น PNG RGBA ขนาด 117×100 พิกเซล ไม่ได้วาดใหม่ ปรับรูปทรง หรือขยายความละเอียด
- `components/GarudaEmblem.tsx` แสดงภาพนี้โดยรักษาสัดส่วน รองรับความกว้างพิกเซลหรือความสูงเซนติเมตร
- `public/garuda.svg` เป็น SVG ที่ฝัง PNG ต้นฉบับเดียวกันเพื่อรองรับ URL เดิม ไม่ใช่ภาพเวกเตอร์ที่วาดขึ้นใหม่
- มีผลกับหน้าตัวอย่างบันทึกข้อความ แบบตอบรับ และรายงานลงเวลาที่ใช้คอมโพเนนต์กลาง รวมถึงการพิมพ์หน้าเหล่านั้น
- รอบนี้ไม่ได้เปลี่ยนตำแหน่งหัวเอกสารหรือฟังก์ชันสร้างไฟล์ Word และยังไม่ได้ deploy
- หากต้องพิมพ์ตราขนาดใหญ่กว่าต้นแบบ ควรจัดหาไฟล์ต้นฉบับความละเอียดสูงจากหน่วยงาน แทนการวาดเลียนแบบ
